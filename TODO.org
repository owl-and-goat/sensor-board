* Crystals                                                         :crystal:
** DONE Local ground islands under Y1 and Y2 (AN2867 structure) - keep as is
CORRECTION to the first review pass, which wrongly said there was no copper
under the crystals. What is actually there: a filled GND =gr_rect= on In1
under each crystal, isolated from the main In1 plane by the keepout gap, a
GND guard ring of graphic lines on F.Cu, a via ring tying the top ring to the
island, and a single-point tie to the rest of ground:
- Y1: via (169.3, 59.05) -> In2 stub -> via (169.5, 58.47) -> main In1 plane
  and B.Cu track to the U2 pin 22 (VSSRF) via.
- Y2: via (178.9, 48.4) -> B.Cu track -> via (179.0, 47.5) -> main In1 plane.
Only crystal-related grounds (Y1.2, C3.2, C5.2) land on the islands. The
keepouts are what create the isolation gap; do not delete them.
